**FlowDesk 1.0.4** for Windows 10/11 (x64) · Free for personal use

### What's new

- The admin helper only takes requests from FlowDesk itself, so other programs can't use it to run things as administrator
- Stopping a flow only closes what that flow started, not every program with the same name (like all of Chrome)
- Stopping one admin flow no longer stops your other admin flows
- Imported flows get their own IDs, so starting or stopping one no longer affects another
